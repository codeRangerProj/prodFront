# ProdFront

Frontend-приложение, построенное на React и TypeScript с использованием архитектуры Feature-Sliced Design (FSD).

## 🚀 Запуск проекта

Установите зависимости:

```bash
npm install
```

Запустите клиент и локальный сервер:

```bash
npm run start:dev
```

После запуска будут доступны:

- клиент: `http://localhost:3000`
- API (`json-server`): `http://localhost:8000`

## 🛠️ Технологии

- React
- TypeScript
- Redux Toolkit
- Webpack
- SCSS Modules
- Storybook
- Jest
- Cypress

## 📂 Архитектура

Проект построен по методологии **Feature-Sliced Design (FSD)**:

```text
src/
├── app
├── pages
├── widgets
├── features
├── entities
└── shared
```
